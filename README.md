# Spotify Scraper

Convert Spotify playlist links to readable text format.

## Overview

This application reads a text file containing Spotify links and outputs a plaintext document with song names and artists in a readable format.

## Project Status

Currently in Phase 0 - Initial scraper development.

## Usage

Provide a text file with Spotify links, and the application will generate a readable playlist format.

## Development

This is a Node.js application. Use the following commands:

```bash
npm start    # Run the application
npm test     # Run tests
npm run lint # Check code quality
```
